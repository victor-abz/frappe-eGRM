# Check a complaint (/docs/citizen/track)







Open &#x2A;*[egrm.risa.gov.rw/grm-portal/track](https://egrm.risa.gov.rw/grm-portal/track)**,
or click **Track** in the top menu.

<Steps>
  <Step>
    ### Type in your tracking code [#type-in-your-tracking-code]

        <img alt="Entering a tracking code" src="__img0" />

    This is the code you were given when you submitted, in the form
    `RDAP-260907-6503`. Type it exactly, including the dashes.
  </Step>

  <Step>
    ### Click Track Complaint [#click-track-complaint]

        <img alt="The tracking result" src="__img1" />

    You are shown the current status, the category, and the date you submitted it.
  </Step>
</Steps>

## What the statuses mean [#what-the-statuses-mean]

| Status          | What it means for you                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **New**         | Received, waiting for an officer to review it.                                                                                  |
| **In Progress** | Assigned to an officer who is working on it.                                                                                    |
| **Resolved**    | The officer has recorded an outcome.                                                                                            |
| **Closed**      | Finished and filed.                                                                                                             |
| **Rejected**    | Not taken forward — usually because it falls outside what this mechanism covers, or there was not enough information to act on. |

## What you will and will not see [#what-you-will-and-will-not-see]

The tracking page deliberately shows only the status, category and submission
date. It does not show your description, your contact details, or the names of
the officers involved. This is so that a tracking code shared with or
overheard by someone else cannot expose personal information.

## If you get stuck [#if-you-get-stuck]

* **"Not found" or no result.** Check the code character by character — the
  letters are the project code and the digits include the date. It is easy to
  read `0` as `O`.
* **You lost the code.** If you gave contact details when you submitted, the
  office can look your complaint up for you. If you chose to stay anonymous,
  there is no way to recover it — you would need to submit again.
* **The status has not changed in a long time.** Contact the office handling
  the project and quote your tracking code.
