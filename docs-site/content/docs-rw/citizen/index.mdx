**Ntukeneye** konti, ijambobanga, cyangwa porogaramu ya telefoni kugira ngo
utange ikibazo. Ibiri kuri iyi paji byose bikorera kuri mushakisha iyo ari yo
yose.

Fungura **[egrm.risa.gov.rw/grm-portal](https://egrm.risa.gov.rw/grm-portal)**.

![Ipaji y'itangiriro y'urubuga rusange rwa eGRM](../img/portal-home-en.png)

## Ibintu bibiri ushobora gukora

| Nshaka… | Aho ukanda |
| --- | --- |
| Gutanga ikibazo gishya | **Submit a Complaint → Start form** |
| Kureba ikibazo namaze gutanga | **Track a Complaint → Enter code** |

Utwo tubuto twombi turi ku ipaji y'itangiriro, kandi turi no muri menu iri
hejuru kuri buri paji.

## Guhindura ururimi

Urubuga rufungurwa mu Kinyarwanda. Kugira ngo urusome mu rundi rurimi,
koresha agasanduku kari mu **mfuruka yo hejuru iburyo** ku ipaji iyo ari yo
yose. Hari amahitamo atatu:

- **Kinyarwanda** (urw'ibanze)
- **Icyongereza**
- **Igifaransa**

Icyo wahisemo gihita gikora, kandi kiguma uko wimuka hagati y'amapaji.

![Urubuga rusange mu Kinyarwanda, hamwe n'agasanduku k'indimi mu mfuruka yo hejuru iburyo](../img/portal-home.png)

<Callout type="info">
Guhindura ururimi bihindura inyandiko n'utubuto gusa. Nta kintu na kimwe
bihindura ku kibazo cyawe, kandi ushobora gusubira ku rundi rurimi igihe icyo
ari cyo cyose.
</Callout>

## Icyo "Mobile App" iri muri menu ikora

Ihuza rya **Mobile App** ni iry'abakozi bo ku rwego rw'ibanze bakusanya
ibibazo ahantu hatari murandasi. Nk'umuturage ntuyikeneye — urubuga rukora
ibyo ukeneye byose.
