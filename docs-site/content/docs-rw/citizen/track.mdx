## Icyo imimerere isobanura

| Imimerere | Icyo bivuze kuri wowe |
| --- | --- |
| **New** (Gishya) | Cyakiriwe, gitegereje umukozi uzagisuzuma. |
| **In Progress** (Kiri gukorwaho) | Cyahawe umukozi uri kugikoraho. |
| **Resolved** (Cyakemuwe) | Umukozi yanditse icyemezo cyafashwe. |
| **Closed** (Cyafunzwe) | Cyarangiye kandi cyabitswe. |
| **Rejected** (Cyanzwe) | Ntigikomeje — akenshi kubera ko kitari mu byo ubu buryo bukemura, cyangwa nta makuru ahagije yo kugikoraho. |

## Ibyo uzabona n'ibyo utazabona

Ipaji yo gukurikirana yerekana gusa imimerere, icyiciro n'itariki cyatangiweho
— ibyo ni ibyagambiriwe. Ntiyerekana ibisobanuro wanditse, amakuru yo
kukugeraho, cyangwa amazina y'abakozi babikoraho. Ibi bituma kode yo
gukurikirana, yaba isangiwe cyangwa yumviwe n'undi muntu, itamugaragariza
amakuru yawe bwite.

## Niba wabuze aho uhera

- **"Not found" cyangwa nta gisubizo.** Genzura kode inyuguti ku yindi —
  inyuguti ni kode y'umushinga naho imibare ikubiyemo itariki. Biroroshye
  gusoma `0` nk'aho ari `O`.
- **Wabuze kode.** Niba warahaye amakuru yo kukugeraho igihe wohereza,
  ibiro bishobora kugushakira ikibazo cyawe. Niba warahisemo kutamenyekana,
  nta bundi buryo bwo kuyibona — wagomba kongera gutanga ikibazo.
- **Imimerere imaze igihe kirekire itahindutse.** Vugana n'ibiro bishinzwe
  umushinga, ubahe kode yawe yo gukurikirana.
