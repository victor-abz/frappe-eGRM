Abakozi bakorera mu gice gitandukanye n'urubuga rusange. Ukeneye konti,
ishyirwaho n'umuyobozi wa sisitemu.

## Kwinjira

Jya kuri **[egrm.risa.gov.rw/login](https://egrm.risa.gov.rw/login)** hanyuma
wandike aderesi y'imeyili n'ijambobanga wahawe.

![Ipaji yo kwinjira](../img/login-en.png)

Nyuma yo kwinjira ugera ahakorerwa **eGRM**.

## Icyapa nyamukuru

![Ahakorerwa eGRM](../img/desk-workspace.png)

Ibice bibiri ni ngombwa:

**Urutonde ruri ibumoso** ruhoraho. Ibiri muri rwo ni:

| Kinyarwanda | Icyongereza |
| --- | --- |
| Shakisha | Search |
| Imenyekanisha | Notifications |
| Ahabanza | Home |
| Andika Ikibazo | Record Issue |
| Ibibazo Bifunguye | Open Issues |
| Iby'integuro Byanjye | My Assignments |

**Amakarita ari hagati** ashyira ibindi byose mu matsinda hakurikijwe ubwoko
bw'akazi — kwakira ibibazo, ibitekerezo, igenzura, imishinga, abakoresha,
n'igenamiterere rya sisitemu. Uzashobora gufungura gusa ayo inshingano zawe
zikwemerera.

Izina ryawe n'imeyili biri hasi ibumoso. Kanda aho kugira ngo usohoke.

<Callout type="info">
Ibyapa by'abakozi byerekanwa mu **Kinyarwanda**, kuko ari rwo rurimi sisitemu
ishyizwemo. Ipaji y'[Inyandiko ziri ku byapa](/rw/docs/glossary) itondekanya
buri nyandiko uzahura na yo n'icyo isobanura mu Cyongereza. Niba wifuza
gukorera mu Cyongereza, saba umuyobozi wa sisitemu guhindura ururimi kuri
konti yawe — bihindura gusa ibyo wowe ubona, ntibihindure ibyo abandi babona.
</Callout>

## Ni izihe nshingano mfite?

Inshingano muri eGRM zerekeye **imirimo**, kandi abakozi benshi bafite nyinshi
icyarimwe. Icyo gitandukanya abakozi babiri akenshi ni **akarere** bagenewe,
atari utubuto bashobora gukanda.

| Niba akazi kawe ari… | Soma |
| --- | --- |
| Kwakira ibibazo by'abaturage no kubyinjiza muri sisitemu | [Umukozi wo ku rwego rw'ibanze](/rw/docs/staff/field-officer) |
| Gusuzuma ibibazo bishya no kubyohereza ku muntu ubikwiye | [Umugenzuzi](/rw/docs/staff/reviewer) |
| Gushyiraho imishinga, uturere na konti z'abakozi | [Umuyobozi w'umushinga](/rw/docs/staff/administrator) |

## Niba wabuze aho uhera

- **Ijambobanga ryawe ntirikora.** Amagambobanga ntiyerekwa umuntu n'umwe,
  bityo kuryongera gushyiraho ni yo nzira yonyine — saba umuyobozi wa sisitemu.
- **Winjira ariko ntacyo ubona.** Ufite konti ariko ntaho uragenerwa gukorera.
  Kugeza igihe umuyobozi akugeneye akarere, nta bibazo wemerewe kureba.
- **Ikibazo wari witeze ntikiboneka.** Ubona gusa ibibazo by'uturere ugenewe.
  Niba ikibazo kiri mu karere gaturanye, ntikizakugaragarira.
