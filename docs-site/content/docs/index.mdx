eGRM is how a problem gets reported, tracked, and fixed. A member of the
public raises a complaint; a government officer records it, routes it to the
right person, and resolves it. Everyone can see where it stands.

This guide assumes no technical background. Pick the description below that
sounds like you.

## How a complaint moves

Every complaint follows the same path, no matter how it arrives:

<Steps>
<Step>
### It is reported

Someone submits it on the public website, or tells a field officer in person,
by phone, by SMS, or through the mobile app. The officer records it for them.
</Step>

<Step>
### It gets a tracking code

The system gives the complaint a code like `RDAP-260907-6503`. Anyone holding
that code can check the status without logging in.
</Step>

<Step>
### It is reviewed and assigned

A reviewer confirms the details and sends it to the officer or department
responsible for that area.
</Step>

<Step>
### It is resolved

The assigned officer investigates, records what was done, and closes it. The
status visible to the public updates at the same time.
</Step>
</Steps>

## About the language

The system opens in **Kinyarwanda**. The public website also offers
**English** and **Français**, and you can switch at any time using the
selector in the top-right corner.

<Callout type="info">
The public website screenshots in this guide show the **English** version, so
they match the English text around them. The staff screens are shown in
**Kinyarwanda**, because that is what staff accounts on this system actually
display. Every staff label is also listed in English on the
[Screen labels](/docs/glossary) page.
</Callout>
