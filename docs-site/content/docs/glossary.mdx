guide in English, use this page to match what is on your screen to what is
written here.

<Callout type="info">
Words that are project data rather than interface text — category names like
*Complaint*, issue types like *Web Form*, and department names — stay in the
language they were entered in when the project was set up. That is why you
will see English words on an otherwise Kinyarwanda screen.
</Callout>
